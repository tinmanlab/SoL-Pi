TIP

네 장치는 서로 다른 낭비를 공격합니다.

Action Fusion은 불필요한 호출, Compact는 오래된 기억, ObservationPack은 큰 데이터의 반복 운반, Reducer는 비싼 모델의 단순 읽기를 줄입니다.

05

RSI를 오해하지 않기

“AI가 스스로 진화했다”는 뜻은 아니다

❌ 이 논문이 하지 않은 것

LLM weights↓ 자기 재학습더 똑똑한 LLM↓ 무한 반복

모델 weight를 스스로 바꾸거나 능력이 폭발적으로 증가한 실험이 아닙니다.

✓ 실제로 한 것

고정 LLM↓ trajectory하네스 분석·수정↓ 더 효율적인 실행

그래서 논문도 강한 RSI가 아니라 RSI-inspired framing을 사용합니다.

06

증거의 경계

어디까지 믿어도 되는가?

강함

실험이 직접 보여준 것

  • 하네스가 같은 모델의 비용·토큰·점수를 크게 바꿀 수 있음
  • 4개 메커니즘이 executable benchmark에서 실제 작동
  • GPT-5.6 Sol에서 찾은 메커니즘이 Opus 5에도 일부 전이
제한적

흥미롭지만 더 필요한 것

  • 모든 모델·코드베이스에 같은 효과가 나는지
  • 20-agent swarm 결과의 반복 재현성
  • 자동 harness search가 인간 설계보다 항상 우월한지
미증명

아직 미래 연구인 것

  • 재귀적 개선이 계속 가속되는 compounding RSI
  • Harness pretraining의 scaling law
  • 성능 손실 없는 보편적 2× efficiency
