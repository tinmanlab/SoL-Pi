Claim boundary

직접 지지

하네스가 실제 영향을 준다

같은 모델에서도 비용·토큰·점수가 크게 달라졌고, 네 메커니즘은 executable benchmark에서 작동했습니다.

제한적

다른 모델에도 일부 전이

Sol에서 찾은 메커니즘이 Opus 5에서도 작동했지만, 모든 모델·코드베이스에 일반화됐다고 보기는 이릅니다.
